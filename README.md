I will provide:

1. A document/PDF containing multiple screenshots of websites that I want you to use as visual and UX references.

2. The official college-fest pamphlet/brochure containing the actual fest information, branding, events, schedule, venue, registration details, prizes, sponsors, contacts, and other content.

3. Any official logos, images, QR codes, or other assets available.

IMPORTANT:

Analyze the reference screenshots and pamphlet BEFORE building the website.

Do not copy any single reference website.

Instead, synthesize the strongest ideas from the references into an ORIGINAL website for my fest.
